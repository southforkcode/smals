# Retired Terms

This document tracks terms that were originally defined, included/referenced from specifications, but have since been removed (or retired) as they are redundant or no longer useful.

## Standards

Retired terms must:

- Not be used, **at all**, in any active specification in this project, or any active documentation (user, API, README.md, AGENTS.md, etc.).
- **Reason** column indicates whether it is removed, replaced, or other explanation. If replaced, it indicates which term replaced it.
