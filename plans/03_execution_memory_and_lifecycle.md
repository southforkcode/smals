# Executable Semantics, Checked Memory and Lifecycle

Use a C++ host interpreter as a differential oracle and a useful early runnable product. Python supplies independent mathematical vectors only. General concurrency semantics are exercised through a deterministic test environment; no multi-agent native profile is invented.

Source: [specification index](../specs/README.md). Delivery and evidence rules: [00](00_delivery_and_evidence.md). All checkboxes are initially open. Commands and implementation paths below are planned interfaces, not existing tools. Each listed row is one increment with a 15-minute active-work ceiling.
