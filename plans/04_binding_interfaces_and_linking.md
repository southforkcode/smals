# Binding, Interfaces, Objects and Static Linking

These increments produce reproducible artifacts before native code is complete. Data-only and synthetic fixtures are valid development evidence but cannot establish executable runtime closure. Authoritative contract adoption remains a dependency of real reference objects/images.

Source: [specification index](../specs/README.md). Delivery and evidence rules: [00](00_delivery_and_evidence.md). All checkboxes are initially open. Commands and implementation paths below are planned interfaces, not existing tools. Each listed row is one increment with a 15-minute active-work ceiling.
