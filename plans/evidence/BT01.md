## Direct verification and reproduction

Raw command argv/stdout/stderr/exit codes: `temp/evidence/BT01/commands.json`; first unsuccessful probe: `initial-commands.json`; hashes: `hashes.json`; environment: `environment.json`. These ignored artifacts are supplemental; the commands, fixture and observations below are durable.

Initial direct compile without `-isysroot` failed with `fatal error: 'cstdio' file not found` (exit 1). Both initial sources stopped at that missing header, so that run does **not** establish successful positive/negative qualification. Investigation with `clang++ -std=c++23 -v -E -x c++ /dev/null` showed missing default C++ header directories; Apple SDK headers already existed. Selecting the installed SDK explicitly resolved this without installation or changing the expected behavior.

Write this exact source to `temp/evidence/BT01/good.cpp`:

```cpp
#include <cstdio>
#include <expected>

static_assert(__clang_major__ == 21);
static_assert(__cplusplus >= 202302L);

constexpr int answer() {
  if consteval {
    return 42;
  } else {
    return 0;
  }
}

static_assert(answer() == 42, "compile-time answer must be 42");

int main() {
  constexpr std::expected<int, int> result = answer();
  std::printf("clang smoke: %d\n", *result);
  return *result == 42 ? 0 : 1;
}
```

Create `bad.cpp` by changing only `static_assert(answer() == 42,` to `static_assert(answer() == 43,`. Use fresh output paths (remove previous `good`/`bad` executables before running):
