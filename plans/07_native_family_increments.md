# Native CPU Family Increments

Twelve family emitters share checked runtime algorithms but own instruction legality, native calls, address translation and monitor transport. Each instruction-form row compares known bytes and executes on an independent engine. Reusing a family emitter does not establish exact-profile compatibility. Kxx-31 is a dispatcher-only integration row: any unmapped primitive needs its own <=10-minute child before it can pass.

Source: [specification index](../specs/README.md). Delivery and evidence rules: [00](00_delivery_and_evidence.md). All checkboxes are initially open. Commands and implementation paths below are planned interfaces, not existing tools. Each listed row is one increment with a 15-minute active-work ceiling.
