# Portable Checked Runtime and Native Lowering

Generate real native-callable checked runtime code from a small privileged Kernel IR. The Kernel IR interpreter is a test tool only; it never substitutes host SMIL semantics for target execution. Conservative stack-slot lowering and packet ABI avoid starting with an optimizing register allocator.

Source: [specification index](../specs/README.md). Delivery and evidence rules: [00](00_delivery_and_evidence.md). All checkboxes are initially open. Commands and implementation paths below are planned interfaces, not existing tools. Each listed row is one increment with a 15-minute active-work ceiling.
